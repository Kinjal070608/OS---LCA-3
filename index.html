Priority CPU Scheduling

Hospital Patient Monitoring System

A bedside monitor runs many software tasks on one CPU. When a patient's heart rhythm turns dangerous, the critical cardiac alert must get the CPU immediately, even if a routine task is running. Preemptive priority scheduling guarantees this. Smaller priority number = higher priority (1 beats 3).

Concept explanation

  • CPU scheduling: the OS decides which ready process uses the CPU next.
  • Priority scheduling: the ready process with the smallest priority number runs first. Ties go to the earlier arrival (FCFS).
  • Preemptive: if a higher-priority process arrives, the running one is interrupted, keeps its remaining time and returns to the ready queue.
  • Why P3 goes first: the critical cardiac alert has priority 1, the best of all tasks, so at time 2 it preempts P2 and the nurse is alerted in time. A late alert is a failure, not a delay.
  • Ready queue: grows when processes arrive or are preempted and shrinks when one is dispatched or completes.
  • Gantt chart: each block shows who owned the CPU, and its width is proportional to the time used.

Viva questions

What is CPU scheduling?

Choosing which ready process gets the CPU, and for how long, so the CPU stays busy.

What is priority scheduling?

An algorithm that gives the CPU to the ready process with the highest priority (smallest number here).

What is preemptive scheduling?

The OS can take the CPU away from a running process when a more important process arrives.

What is a process?

A program in execution, with its own code, data, state and registers.

What is arrival time?

The time at which a process enters the ready queue.

What is burst time?

The total CPU time a process needs to finish.

What is completion time?

The time at which a process finishes execution.

What is turnaround time?

Completion time − arrival time: the total time from arrival to finish.

What is waiting time?

Turnaround time − burst time: the time spent waiting in the ready queue.

What is starvation?

A low-priority process waits indefinitely because higher-priority processes keep arriving. Aging (slowly raising priority) is a fix.

Preemptive vs non-preemptive?

Preemptive can interrupt a running process; non-preemptive lets it run until it finishes or blocks.

What is a real-time deadline?

The latest time by which a task must finish. For a critical cardiac alert, missing it is a failure, not just a delay.

What is an interrupt?

A hardware signal (here, the heart-rate sensor) that makes the OS react immediately by making a task ready.

Why is priority scheduling useful in a hospital monitoring scenario?

Critical alerts have a deadline. Preemption gives them the CPU at once, while routine tasks such as vital-sign updates and reminders wait.
